安全说明

本工具是单个本地网页文件，以下每一条你都可以自己验证
  • 全程离线：页面不发起任何网络请求，不加载任何外部脚本、字体、图片或统计代码。断网状态下同样可以完整使用。验证方法：按 F12 打开开发者工具 → Network 面板 → 操作一遍页面，只会看到本机文件，没有任何外部请求。
  • 数据存在本浏览器：工序、单价、用量、备注等只保存在你自己浏览器的本地存储（localStorage）里，关掉页面再打开会自动恢复，不会上传到任何服务器。注意：清除浏览器数据、换设备或换浏览器都会让这些数据消失——重要数据请用页面底部「导出数据备份」存成文件。
  • 导出文件不含宏：导出的 .xlsx / .docx 是纯数据 OOXML 包，没有任何 VBA 宏或可执行代码；.pdf 为图像页。这三种格式本身不是可执行文件，双击只会被 Excel / Word / PDF 阅读器打开。
  • 无任何安装行为：这是 .html 文件，不是 .exe / .msi，双击仅由浏览器打开，不写注册表、不装服务、不修改系统设置。
  • 输入已做转义：所有自定义名称（工序名、型号等）在渲染和导出时都做了 HTML / XML 转义，不会被当作代码执行；导出的表格单元格按纯文本写入，不会被 Excel 当成公式运算。
  • 关于登录口令（请务必了解）：口令是在你本机浏览器里校验的，用途是挡住无关人员随手打开，不等于密码学意义上的加密保护——校验逻辑就写在文件里，懂技术的人可以绕过；若把文件公开托管（例如 GitHub Pages），源码和口令摘要同样公开，6 位纯数字口令可被离线爆破。要真正控制「谁能看」，必须上服务端认证。
  • 来源校验：如果这个文件是别人转发给你的，请确认来源可信。文件是否被人改动过，可用系统自带命令 certutil -hashfile 文件名 SHA256 计算哈希，与来源方提供的值比对。

create table if not exists public.shared_state (
  id text primary key,
  payload jsonb not null,
  rev bigint not null default 1,
  updated_at timestamptz not null default now()

alter table public.shared_state enable row level security;
create policy "shared rw" on public.shared_state
  for all to anon using (true) with check (true);
grant all on public.shared_state to anon;
